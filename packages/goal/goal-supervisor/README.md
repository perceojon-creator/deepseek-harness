# @deepseek-ai/dsh-goal-supervisor

English | [中文](README.zh.md)

## Summary

`dsh-goal-supervisor` provides a five-layer metacognitive supervisor that prevents premature goal completion, especially by fast/flash models, using an architecture modeled on the ACC and dlPFC prefrontal cortex.

## Known Limitations and Deferred Work

- Currently requires live LLM adapter when Layer 4 is invoked.
